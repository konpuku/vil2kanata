# kanata-switcher

自作キーボードの接続状態に合わせて kanata を自動で起動・停止する、タスクトレイ常駐ツールです。

- 自作キーボードが**接続されている間は kanata を停止** (リマップ無効)
- 自作キーボードが**外れると kanata を起動** (リマップ有効)
- タスクトレイのアイコンで **自動 / 常に有効 / 常に無効** を切り替え

Windows 10/11 標準の Windows PowerShell 5.1 だけで動きます (追加インストール不要)。

## アイコンの見方

| アイコン | 状態 |
|---|---|
| 緑の **K** | リマップ有効 (kanata 実行中) |
| 青の **K** | リマップ無効 (自作キーボード接続中) |
| 灰の **K** | リマップ無効 (常に無効) |
| 赤の **!** | エラー (kanata が起動できない) |

アイコンにマウスを乗せると詳しい状態が表示されます。

## セットアップ

1. このフォルダ (`kanata-switcher`) を好きな場所に置きます
2. `start-kanata-switcher.vbs` をダブルクリックして起動します
   (初回は同じフォルダに `kanata-switcher.json` が作られます)
3. タスクトレイのアイコンを右クリック →「**設定ファイルを開く**」で次の 2 つを設定し、保存します
   - `kanataExe`: kanata の実行ファイル (例: `kanata_windows_tty_winIOv2_x64.exe`)
   - `kanataConfig`: 使用する .kbd ファイル
   - 相対パスはこのフォルダが基準です。`kanata-switcher.sample.json` も参考にしてください
4. 右クリック →「**kanata を再起動 (設定を再読み込み)**」
5. 自作キーボードを接続した状態で、右クリック →「**自作キーボードを登録...**」から自作キーボードにチェックを入れて保存します
   - 一覧にはキーボード/HID デバイスが `VID_xxxx&PID_xxxx` ごとに表示されます
   - どれか分からないときは、自作キーボードを抜き差しして「更新」を押し、増減した項目を選んでください
   - ノートPC本体のキーボードは選ばないでください
6. Windows 起動時に自動で起動したい場合は、右クリック →「**Windows 起動時に自動実行**」にチェック

kanata-switcher が kanata を起動・停止するので、**kanata 自体は別途起動しないでください**
(2 つ動くと 2 重にリマップされます。起動時に、設定と同じ実行ファイルの kanata が残っていれば停止します)。

## メニュー

| 項目 | 動作 |
|---|---|
| 自動 (自作キーボード接続中は無効) | 既定。接続状態に合わせて自動で切り替え |
| 常に有効 / 常に無効 | 接続状態に関係なく固定 |
| アイコンをダブルクリック | 今と逆の状態で固定 (自動に戻すにはメニューから) |
| 自作キーボードを登録... | 自動切り替えの対象にするキーボードを選択 |
| kanata を再起動 | .kbd や設定ファイルを変更したとき、エラーから復帰するとき |
| 設定ファイルを開く | `kanata-switcher.json` をメモ帳で開く |
| Windows 起動時に自動実行 | スタートアップにショートカットを作成/削除 |
| 終了 | kanata も停止して終了 |

## 設定ファイル (kanata-switcher.json)

| 項目 | 既定値 | 説明 |
|---|---|---|
| `kanataExe` | `kanata_windows_tty_winIOv2_x64.exe` | kanata の実行ファイル |
| `kanataConfig` | `keymap.kbd` | .kbd ファイル |
| `kanataArgs` | `-n` | kanata に渡す追加オプション (`-n` は起動時の 2 秒待ちを省略) |
| `deviceIds` | `[]` | 自作キーボードの ID (デバイス ID に含まれる文字列。`VID_FEED&PID_0000` 等) |
| `mode` | `auto` | `auto` / `on` / `off` |
| `pollIntervalMs` | `2000` | 接続状態を確認する間隔 (ミリ秒) |

## 注意

- 接続を検知してから切り替わるまで、最大で `pollIntervalMs` 程度かかります
- 自作キーボードの接続中はノートPC本体のキーボードもリマップされません (kanata の標準版は入力元のキーボードを区別できないため)
- JIS 英数/かなキーを F13/F14 に置き換えるレジストリ設定をしている場合、kanata 停止中はノートPCのそれらのキーが F13/F14 として入力されます
- kanata が起動直後に終了を繰り返す場合は赤いアイコンになります。コマンドプロンプトで
  `kanata_windows_tty_winIOv2_x64.exe --cfg keymap.kbd --check` を実行して設定を確認し、修正後に「kanata を再起動」を押してください
- PowerShell の実行ポリシーは `start-kanata-switcher.vbs` の中で `-ExecutionPolicy Bypass` を指定しているため、変更不要です
